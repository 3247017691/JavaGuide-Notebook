这里统一整理 JavaGuide 中适合按路线学习的内容，帮助你根据目标选择 2026 最新版学习路径，而不是在大量文章里来回跳。

如果你正在准备后端面试，优先看 Java 后端路线；如果你已经有 Java/Go 后端基础，想进入 AI 应用开发或 Agent 方向，可以从 AI 应用开发路线开始；如果你希望提升独立交付能力，可以看全栈学习建议；如果你想准备测试开发、自动化测试或 AI 测试方向，可以看测开学习路线。

后端方向

  • Java 后端学习路线（2026 最新版）：从 Java 基础、集合、并发、JVM、Spring、数据库、分布式到项目实践，适合 Java 后端系统学习和求职准备。

AI 方向

  • Java/Go 开发者 AI 应用开发与 Agent 学习路线（2026 最新版）：面向后端开发者，按大模型基础、LLM API、Prompt、RAG、Agent、工程化和项目实战拆解学习路径。
  • 后端开发者转型 AI Agent 学习建议（2026 最新版）：先判断是否适合转型，再看 Java AI 与 Python AI 怎么选、能投什么岗位、应该如何学习。

全栈方向

  • 后端开发者全栈学习路线（2026 最新版）：结合 AI 编程工具，讲清后端开发者如何补齐前端能力，逐步具备独立交付完整功能的能力。

测试开发方向

  • 测试开发学习路线（2026 最新版）：面向测开、自动化测试和质量工程方向，覆盖测试理论、接口/UI/性能自动化、CI/CD、测试平台、AI 辅助测试和 AI 应用评测。
