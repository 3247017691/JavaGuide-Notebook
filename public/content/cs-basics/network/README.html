学习重点

  • 网络分层的核心价值是拆分复杂通信问题，每一层只解决自己的职责。
  • HTTP、HTTPS、DNS 是后端开发最常用的应用层知识。
  • TCP 高频考点集中在连接管理、可靠传输、拥塞控制、TIME_WAIT 和 Keepalive。
  • ARP、NAT 等网络层知识能帮助理解局域网通信、内外网访问和排障。
  • 面试中要能结合一次完整请求，把协议、连接、加密、解析和传输串起来。
