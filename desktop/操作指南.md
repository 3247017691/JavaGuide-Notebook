# 面试工作台 · 操作指南

这套桌面把 **JavaGuide 离线小抄** 与 **JBL 火箭题库** 装进同一块 macOS 风格的工作台：顶部是菜单栏，中间是桌面与窗口，底部是程序坞。两个应用都以"窗口 + 标签页"的方式打开，互不干扰。

---

## 一、没有右键怎么用（重点）

很多网页环境禁用右键，触摸屏上也没有右键。这套外壳为此把**所有动作都做了四条入口**，任何一条被堵住都不影响其余三条：

| 入口 | 怎么做 |
|---|---|
| ① 长按 0.5 秒 | 按住不放（鼠标左键或手指均可，触摸屏同样可用） |
| ② 顶部菜单栏 | 点菜单名（工作台 / 面试工作台 / 文件 / 前往 / 显示 / 窗口 / 帮助） |
| ③ 工具栏 ⋯ 按钮 | 每个窗口右上角的「⋯」，等于当前窗口的完整菜单 |
| ④ 命令面板 | `Ctrl/⌘ + K`，见第五节 |

**长按的位置决定菜单内容**：

| 长按位置 | 得到的菜单 |
|---|---|
| 桌面空白处 | 桌面菜单：全局搜索、打开应用、关闭全部窗口、重新载入桌面、显示偏好、操作指南、关于本机 |
| 标签页上 | 标签菜单：切换到该标签页、复制为新标签页、重新载入、关闭标签页、关闭其他标签页、复制地址 |
| 侧栏条目上 | 「在当前页打开 / 新标签页打开」二选一 |
| 窗口内容里（小抄、题库正文） | 窗口菜单：后退/前进、显隐侧边栏、浏览器打开、复制地址、半屏/并列/缩放、最小化、关闭窗口；小抄里还有「整章标记已读」 |
| 程序坞图标 / 桌面图标 | 应用菜单：打开或聚焦窗口、按标签页跳转、关闭标签页/窗口、新标签页打开目录、在浏览器新标签页打开 |
| 菜单栏右侧「进度库」圆点 | 点击或长按可重新检测进度库状态并查看说明 |

> 提示：在触摸屏上长按正文可能先触发"选中文字"，从**标题栏、标签页、侧栏、图标**等非文字区域开始长按更稳。

## 二、红绿灯按钮

每个窗口左上角有三颗灯（鼠标悬停会显示符号）：

- 🔴 **关闭窗口**（红色 ×）
- 🟡 **最小化**：窗口会**收进底部程序坞**——程序坞分隔线右侧出现该窗口的小图标，点它即可恢复。也可以用 `Ctrl/⌘ + M`。
- 🟢 **缩放窗口**：在"原始大小"与"最大化（贴住菜单栏下沿与程序坞上沿）"之间切换；双击标题栏等效。

## 三、窗口管理

- **拖动**：按住标题栏拖动；**缩放**：拖窗口边缘。
- **半屏**：`Ctrl/⌘ + ⇧ + ←/→` 把窗口贴到左/右半屏（菜单：显示 → 窗口居左/居右半屏）。
- **两窗并列**：`Ctrl/⌘ + ⇧ + F`（需要恰好两个窗口）。
- **最小化 / 全部显示**：`Ctrl/⌘ + M` 收进程序坞；`Ctrl/⌘ + ⇧ + M` 隐藏全部窗口，再按一次前置全部。
- **切换窗口**：`Ctrl/⌘ + \``（反引号）循环聚焦。
- **程序坞**：左侧是两个应用（运行中底部有小圆点），分隔线之后是**最小化的窗口**；`Ctrl/⌘ + 1 / 2` 直开应用。

---

## 四、侧边栏与标签页

- 点侧栏条目 = 在**当前标签页**打开；**长按**侧栏条目 = 可选择**在新标签页打开**。
- 拖**侧栏与正文之间那条缝**可改宽度，**双击那条缝**复位；键盘也可以：`Tab` 走到分隔线后用 `←` `→`。
- 显示偏好里可统一设定默认侧栏宽度（菜单：工作台 → 显示偏好…）。
- 显隐侧栏：`Ctrl/⌘ + B`，或工具栏侧栏按钮。
- 标签页可**拖动排序**；**双击**标签、按 `Delete`、或鼠标**中键**均可关闭；标签内 `Ctrl + ←/→` 也可切换标签。
- 只有 1 个标签时标签条自动收起，把宽度全部让给正文。
- 新建 / 关闭：`Ctrl/⌘ + T` / `Ctrl/⌘ + W`；关闭整个窗口：`Ctrl/⌘ + ⇧ + W`。
- 后退 / 前进：`Ctrl/⌘ + [` / `]`；切换标签页：`Ctrl/⌘ + ⇧ + [` / `]`。

## 五、命令面板（全局搜索）

按 `Ctrl/⌘ + K` 呼出，可搜索**文章、题目、章节**（跨小抄与题库）以及执行命令：

- 范围切换：全部 / 小抄 / 题库；"最近打开"入口在菜单：文件 → 最近打开。
- 操作：`↑` `↓` 选择，`Enter` 打开，`Ctrl/⌘ + ⇧ + Enter` 在**新标签页**打开，`Esc` 关闭。
- 内置命令（输入关键字即可过滤）：外观：浅色 / 深色 / 跟随系统、恢复或降低透明度、切换侧边栏、新建 / 关闭标签页、窗口居左 / 居右半屏、两窗并列排布、显示偏好设置、操作指南、键盘快捷键一览、关闭全部窗口、重新载入桌面、打开小抄 / 火箭题库。

## 六、键盘快捷键总表

> Windows 上按 Ctrl，macOS 上按 ⌘，两者等价。**在窗口内容里（iframe 内）按这些组合同样有效**——小抄与题库里装了桥接脚本，会把按键转交给桌面外壳处理。

| 功能 | 快捷键 |
|---|---|
| 打开第 1 / 2 个应用 | `Ctrl/⌘ + 1 / 2` |
| 全局搜索与命令面板 | `Ctrl/⌘ + K` |
| 新建标签页 | `Ctrl/⌘ + T` |
| 关闭标签页 / 窗口 | `Ctrl/⌘ + W` ／ `⇧ + W` |
| 切换标签页 | `Ctrl/⌘ + ⇧ + [ ／ ]` |
| 后退 / 前进（当前标签页） | `Ctrl/⌘ + [ ／ ]` |
| 重新载入这一页 | `Ctrl/⌘ + R` |
| 显示 / 隐藏侧边栏 | `Ctrl/⌘ + B` |
| 外观：跟随系统 → 浅 → 深 | `Ctrl/⌘ + ⇧ + D` |
| 窗口居左 / 居右半屏 | `Ctrl/⌘ + ⇧ + ← ／ →` |
| 两窗并列排布 | `Ctrl/⌘ + ⇧ + F` |
| 最小化 / 缩放窗口 | `Ctrl/⌘ + M` ／ `⇧ + ＝` |
| 切换到下一个窗口 | `Ctrl/⌘ + \`` |
| 打开这份快捷键表 | `?`（Shift + /） |
| 操作指南（没有右键怎么用） | `Ctrl/⌘ + /` |
| 关闭当前浮层 / 菜单 | `Esc` |

## 八、外观与显示偏好

- 外观三态：**跟随系统 / 浅色 / 深色**，`Ctrl/⌘ + ⇧ + D` 循环切换；主题会自动同步到小抄与题库内部（夜读联动）。
- **降低透明度**：玻璃退成实面，弱光环境更易读（菜单：显示 → 降低透明度）。
- 顶部菜单栏右侧：**进度库圆点**（划线与掌握进度存于本机 MySQL；未启动时阅读与搜索不受影响）与时钟（点时钟看"关于本机"）。

## 九、常见问题

- **窗口不见了？** 看程序坞分隔线右侧的最小化图标，点一下恢复；或按 `Ctrl/⌘ + ⇧ + M` 前置全部窗口；`Ctrl/⌘ + \`` 循环切换。
- **按钮行为和文档对不上 / 改动没生效？** 浏览器可能缓存了旧版资源，按 `Ctrl + F5`（macOS：`⌘ + ⇧ + R`）硬刷新一次。
- **触摸屏长按总选中文字？** 换到标题栏、标签页、侧栏条目、程序坞图标等非文字区域长按，触发的是同一套菜单。
- **快捷键在窗口内容里失灵？** 确认不是处于输入框输入状态；应用内已装桥接脚本，多数组合键会自动转交给外壳。
